Fenton Nonlinear Wave Calculator

50-mode stream-function/Fourier solver for steady, finite-amplitude waves with optional collinear current. It solves the nonlinear state vector using height continuation, finite-difference Jacobians, SVD-stabilised Newton iteration, line search, admissibility checks and engineering post-processing.
